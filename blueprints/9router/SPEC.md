# 9router

All-in-one AI router connecting 40+ AI providers & 100+ models.

## Ports

- HTTP: 3000

## Environment

- `PORT`: Server port (default: 3000)
- `DATABASE_URL`: PostgreSQL connection string (optional, uses SQLite if not set)
- `OPENCLAW_API_KEY`: API key for OpenClaw (optional)
- `GITHUB_TOKEN`: GitHub token (optional)

## Services

- Database: SQLite (built-in) or PostgreSQL (optional)
